Appearance

{#- These are per-person and per-browser, kept in localStorage rather than on the server. Two reasons: nobody should have to wait for a round trip to change a theme, and the choice belongs to the machine someone is sitting at — the same person on a bright screen and a dark one wants different answers, and a server-side preference would fight that. They are the one part of this app that needs JavaScript. Everything a report depends on works without it; a theme toggle is a preference, and the density control has always been marked `data-js-only` for the same reason. -#}

Theme

System follows your operating system. The dark palette is measured against the same contrast thresholds as the light one, not picked by eye.

Row density

Comfortable adds height to every list row. Compact fits more on a screen, which matters most on the runs list.

Theme and density need JavaScript, so they are not available here. Nothing a report depends on does.
