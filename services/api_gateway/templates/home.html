Draft a preclinical report, with every number cited

Pick a report type, give it a compound, and the app pulls what that report is bound to — study documents, warehouse tables, Confluence pages — drafts the narrative around the data, and cites every value back to the study, page, cell or query it came from. You review it; the app never signs anything off.

  1. 1 Choose a report type. Six ship with the app — candidate selection, nonclinical safety, DMPK/ADME, target assessment, IB sections, compound profile. Browse the library.
  2. 2 Name the compound. The setup screen shows which sources will resolve before you commit, so there are no surprises mid-run.
  3. 3 Review the cited draft. Each paragraph shows whether it is backed by retrieved data. Claims the model could not evidence are marked, not hidden.
